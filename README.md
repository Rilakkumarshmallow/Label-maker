# ラベルメーカー（A-ONE 31297対応）

A-ONE 31297（25行×8列・200面）のラベル印刷を、できるだけノーミス・最短時間で行うための印刷支援ツールです。

## できること

- キット（複数材料のセット）の登録・管理
- キット選択＋追加ラベルを組み合わせた印刷データの作成
- 200面を超える場合の自動シート分割
- シート別プレビュー（実際の印刷レイアウトを再現）
- 印刷専用レイアウト（mm単位で用紙に合わせて調整可能）
- 長い商品名の自動文字サイズ調整・自動2段組み
- 改行用語辞書（画面から単語を追加・削除できる、自然な改行位置の調整機能）
- 印刷履歴の保存・復元（最大5件）
- 前回の続きから印刷を開始する機能

## 想定環境

- ラベル：A-ONE 31297
- プリンタ：EPSON EW-M752T
- ブラウザ：Google Chrome（印刷時は余白「なし」・倍率「100%」を推奨）

## 使い方

公開URLを開くだけで利用できます。ブラウザだけで動作し、サーバーへの通信は行いません。

データ（キット・履歴・辞書）はブラウザ内（localStorage）に保存されるため、**別の端末・別のブラウザでは共有されません**。
